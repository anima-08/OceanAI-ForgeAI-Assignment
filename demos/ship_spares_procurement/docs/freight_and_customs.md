# Freight and Customs Pricing

## Freight and Insurance Bands

| Shipment weight | Freight cost (USD) | Insurance rate on merchandise value |
| --- | ---: | ---: |
| 0-100 kg | 20 | 5% |
| 101-200 kg | 30 | 10% |
| 201-300 kg | 40 | 15% |
| 301-400 kg | 50 | 20% |
| 401-500 kg | 60 | 25% |
| 501 kg and above | 70 | 30% |

Freight is a single charge per shipment, not a per-unit charge.

## Customs Fees

- Standard shipment: 5% of merchandise value.
- Expedited shipment: 10% of merchandise value.

## Hazardous-Goods Surcharge

A hazardous-goods surcharge of 10% of merchandise value applies when the shipment contains hazardous materials. Non-hazardous shipments do not pay this surcharge.

## Landed-Cost Formula

`Total landed cost = merchandise value + insurance + freight + customs fees + hazardous-goods surcharge`

Insurance is calculated from the merchandise value using the rate for the shipment-weight band.

## Worked Example: Non-Hazardous Standard Shipment

- 10 units at USD 120 each: merchandise value = USD 1,200.
- Shipment weight: 400 kg, so freight = USD 50 and insurance rate = 20%.
- Insurance: 20% x USD 1,200 = USD 240.
- Standard customs: 5% x USD 1,200 = USD 60.
- Hazardous-goods surcharge: USD 0 because the shipment is non-hazardous.
- Total landed cost: USD 1,200 + USD 240 + USD 50 + USD 60 = USD 1,550.

## Worked Example: Hazardous Expedited Shipment

- 10 units at USD 120 each: merchandise value = USD 1,200.
- Shipment weight: 400 kg, so freight = USD 50 and insurance rate = 20%.
- Insurance: USD 240.
- Expedited customs: 10% x USD 1,200 = USD 120.
- Hazardous-goods surcharge: 10% x USD 1,200 = USD 120.
- Total landed cost: USD 1,200 + USD 240 + USD 50 + USD 120 + USD 120 = USD 1,730.
